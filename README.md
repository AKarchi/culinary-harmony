A beautifully designed, interactive recipe web application celebrating Asian cuisine. Culinary Harmony allows users to explore recipes, use an interactive cooking mode, and share their own culinary creations with the community.

 **Live Demo:** https://culinary-harmony-three.vercel.app/

## ✨ Features
- **Interactive Splash Screen:** Elegant animations with floating lanterns and traditional scroll effects.
- **Recipe Explorer:** Filter recipes by cuisine (Japanese, Chinese, Filipino, Korean, Thai) and meal type.
- **Cooking Mode:** A distraction-free, step-by-step cooking interface with a built-in timer.
- **Community Recipes:** Users can submit their own recipes, stored securely in a Supabase database.
- **Smart Fallbacks:** Custom image fallbacks and URL cleaning for community-submitted links.

## ️ Tech Stack
- **Frontend:** Vanilla HTML5, CSS3, JavaScript (ES6+)
- **Animations:** Anime.js
- **Backend & Database:** Supabase (PostgreSQL)
- **Hosting:** Vercel / Netlify

##  Getting Started
1. Clone the repository: `git clone https://github.com/AKarchi/culinary-harmony`
2. Open `index.html` in your browser.
3. *(Optional)* Create a `.env` or update `script.js` with your own Supabase URL and Anon Key if you want to connect to your own database.
